# Nexus Loop 8-Minute Presentation Kit

Use this folder as the speaking guide for the 28-slide deck. The target runtime is exactly 8:00, including the 25-second product video on slide 11.

## Files

- `full-script.md` has the complete spoken script with timing.
- `cue-cards/` has one short note per slide for presenting from a second screen.
- `rehearsal-sheet.md` is the compact run-through version.
- `timing.csv` is the machine-checkable timeline.

## Timing Rules

- Speak at a calm product-demo pace, around 115 words per minute.
- Do not explain every metric. Name the metric, say what it proves, then move.
- Slide 11 gets 30 seconds total: 3 seconds to introduce, 25 seconds for the video, 2 seconds to transition.
- If running long, cut detail from slides 20, 21, and 26 before cutting the problem or proof slides.
